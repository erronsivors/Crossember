# Crossember (app)

Личный мульти-хаб стримера. ТЗ и этапы — `../ТЗ.md`.

## Запуск
```
npm install      # один раз
npm run dev      # режим разработки (горячая перезагрузка)
npm run build    # сборка в out/
npm start        # запуск собранной версии
npm run typecheck
npm run dist     # установщик Windows: dist/Crossember-Setup-<версия>.exe и .sha256
```

## Установщик для друзей
`npm run dist` собирает установщик (electron-builder, NSIS) и пишет рядом файл с SHA-256. Настройки сборки — `electron-builder.yml`.
- Перед сборкой нужен `resources/youtube/oauth-client.json` (общий клиент YouTube, в Git его нет), иначе друзьям придётся
  заводить свой клиент. При сборке он вшивается в программу закодированным (не файлом), поэтому установщик можно выкладывать
  в GitHub Releases. Клиент Kick в установщик не кладётся.

## Выпуск обновления
1. Поднять `"version"` в `package.json` (например, 0.1.0 → 0.2.0), закоммитить и отправить (`git push`).
2. Написать `release-notes.md` — пункты `- что изменилось`, коротко. Их друзья увидят в окне «Что нового».
3. `npm run release` — проверит, что всё закоммичено и отправлено, соберёт установщик и создаст релиз `v<версия>` (нужен вход в `gh`).
Установленный Crossember раз в 6 часов спрашивает у GitHub последнюю версию, предлагает «Скачать сейчас / Позже»,
показывает процент, затем «Что нового» и «Установить и перезапустить». Целостность файла проверяется по SHA-512 из `latest.yml` релиза.
- Подписи кода нет, поэтому Windows при первом запуске покажет «Windows защитил ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- Как другу проверить файл: в PowerShell `Get-FileHash .\Crossember-Setup-0.1.0.exe` — хэш должен совпасть с `.sha256`.
- Ставится в профиль пользователя без прав администратора, можно выбрать папку. Обновления — через GitHub Releases (ниже).
  Данные (`%APPDATA%\Crossember`) при удалении программы остаются.
- Запускается только одна копия Crossember: если открыта версия из `npm run dev`, установленная просто передаст ей окно.

## Что есть (этап 0)
- Окно в стиле ERRON: Главная, События, Оверлеи, Подключения (диагностика + журнал), Настройки.
- Подключение к OBS (obs-websocket v5): сцена, эфир, запись, разрешение/FPS, авто-переподключение.
  OBS → Инструменты → Настройки WebSocket-сервера → включить, скопировать пароль → «Подключения» → OBS.
- Сервер оверлеев `127.0.0.1:47832`, оверлей алертов (тестовые события из «Событий»).

## Безопасность
- Electron: contextIsolation + sandbox, без nodeIntegration, CSP, запрет навигации/окон/разрешений, IPC только от своего окна.
- Секреты: `safeStorage` (Windows DPAPI) в SQLite; без шифрования не сохраняются.
- Сервер: только loopback, ключ в каждой ссылке/WebSocket (сравнение за постоянное время), проверка Host и Origin.
- Оверлеи выводят пользовательский текст только через `textContent`.

## Где данные
`%APPDATA%\Crossember\data\hub.sqlite3` (настройки, события, зашифрованные секреты).
