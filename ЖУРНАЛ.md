# Журнал решений Crossember

Короткие записи по итогам этапов: что решили и почему, что проверено, что осталось открытым. Пишут и Claude Code, и Codex. Правила ведения — в скилле `ekonom` (раздел «Журнал решений проекта»).

Как читать: целиком не читать. Сначала «Открытые вопросы» и последние 2–3 записи, остальное — поиском (`rg -n "аукцион" ЖУРНАЛ.md`).

Формат записи (5–10 строк, новые сверху, под «Открытыми вопросами»):

```
## ГГГГ-ММ-ДД — <этап или тема> (<кто: Claude / Codex>)
Решили: ... (почему: ...)
Проверено: ... (чем: тест, сборка, вживую в OBS — или «вживую не проверено»)
Открыто: ...
Где: коммит <хэш>, файлы <пути>
```

Без секретов, токенов, IP, личных путей и чужих материалов: репозиторий публичный.

## 2026-11-17 — Обновления через GitHub, ключ YouTube в сборке, правки редактора (Claude, ревью Codex)
Решили: пользователь сделал репозиторий публичным ради обновлений, поэтому релизы — в GitHub Releases. electron-updater 6.8.11: «Есть новая версия — Скачать сейчас / Позже», процент, «Что нового» по пунктам из описания релиза, «Установить и перезапустить» (или при выходе); «Позже» — строка с кнопкой под «Обратной связью»; выключатель и «Проверить сейчас» в Настройках. Это отход от ТЗ «без автозагрузки» по решению пользователя: качает и ставит только по кнопке. Ключ YouTube вшивается в main при сборке (XOR+base64), файлом в установщик не идёт — чтобы автосканеры не нашли его в публичном релизе. `npm run release` — проверка чистого дерева и push, сборка, `gh release create --target <sha>`.
Редактор алертов: Ctrl+C / Ctrl+V слоя (сдвиг 30 px, лимит 40 слоёв); «Убрать анимацию» сохраняет кадры в `keyframesOff` → «Вернуть анимацию»; «Без покачивания» (появление и уход остаются); переключатель «Персонаж дышит» для угловых сцен. Подсказки «!» — через portal поверх окна, в пределах экрана.
Проверено: tsc, сборка, установщик пересобран; в собранной программе проверка обновлений отработала («нет опубликованных версий» — тихо), файла ключа рядом нет, вшитый ключ раскодируется; тесты calmKeyframes и разбора описания релиза. Ревью Codex: 6 замечаний исправлено. Окно обновления и полный цикл обновления вживую не проверены (нет релиза), редактор вживую не проверен.
Открыто: подлинность обновления — только SHA-512 из того же релиза; при взломе аккаунта GitHub можно подменить. Вариант — подпись релиза своим ключом с проверкой в программе.
Где: `app/src/main/core/updater.ts`, `app/src/renderer/src/Update.tsx`, `app/scripts/release.mjs`, `app/electron.vite.config.ts`, `youtube.ts`, `AlertEditor.tsx`, `components.tsx`.
